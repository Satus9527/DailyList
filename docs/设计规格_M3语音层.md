## 1. 全局约定（双端必须一致，承袭 M1/M2）

1. **单一事实源（P0-4 防漂移）**：拆分标点集、长停顿阈值、是否含顿号/换行**全部来自 `shared/asr_split_config.json`**（见 §5.3）。Swift/Kotlin **禁止硬编码**任何拆分常量（含 `1200`、`{ 。！？； }`）；解析时机：App 启动读取一次，缓存为单例 `ASRSplitConfig`。
2. **拆分与识别解耦**：语音层（`ASRController`）只产出 **partial（流式中间）** 与 **final（已确定句段）** 文本，**不决定如何切分**（切分是领域层 `VoiceTaskSplitter` 职责，见 §5）。平台层依据 `splitPauseThresholdMs` 仅决定「何时把当前缓冲作为一个 final 边界吐出」。
3. **领域层不依赖平台 API**：`VoiceTaskSplitter` 仅依赖 `ASRSplitConfig`（纯数据）与 `TaskRepository`（M1 协议），不 import Speech / SpeechRecognizer。
4. **落库契约（M1 对齐）**：语音落库经 `TaskRepository.add(_:)`，字段 `source = .voice`（raw `"voice"`）、`date = 本地 yyyy-MM-dd 今日`、`title` ≤ 500 字、`categoryId` 默认「其他」、`priority` 默认中、`updatedAt` 写入、`syncState` 默认 local。不新增 Task 字段（来源已在 `source` 枚举预留）。
5. **时间**：所有 `remindAt`/`updatedAt` 用设备本地时区绝对时刻（同 M1 §1.2 / M2 §1）。
6. **失败兜底优先**：任何语音链路异常不阻断核心记录流；降级到文字输入（R-X1 / AC-6）。
7. **隐私（P0-1）**：联网识别时音频可能发往系统厂商识别服务（Apple/Google），非本 App 自有服务器；不附带账号与待办写回；v1 无云端持久化/上传待办的写路径（§8）。

## 2. `ASRController` 协议 / 接口（平台无关，双端精确签名）

> 协议只负责「持续听 → 产出 partial/final 文本流」与权限/可用性。拆分、落库均不在协议内。

### 2.1 Swift 协议（async/await 风格，与 M1/M2 一致）

```swift
import Foundation

/// 权限状态
enum PermissionState: Equatable {
    case notDetermined   // 未请求过
    case granted         // 已授权
    case denied          // 用户拒绝（麦克风 / 语音识别）
    case restricted      // 系统限制（如家长控制）
    case unavailable     // 设备不支持 / 语言包缺失到完全不可用
}

/// 平台无关 ASR 抽象；v1 实现 NativeASRController（iOS），v1.1 可加 Xfyun/Whisper 同协议替换
protocol ASRController {
    /// 当前是否可用（语言包/能力层判断；不触发权限弹窗）
    var isAvailable: Bool { get }

    /// 请求授权（麦克风 + 语音识别）。首次调用弹系统授权；返回最终状态
    func requestPermission() async -> PermissionState

    /// 开始持续听。
    /// - onPartial: 流式中间结果（边说边显，实时刷新输入框）
    /// - onFinal:   一个确定句段边界（句末标点 / 长停顿 / 端侧识别结束）产出的最终文本，调用方据此落库
    /// 实现内部维护 AVAudioEngine / SpeechRecognizer 持续喂缓冲；停止需调 stop()
    func start(onPartial: @escaping (String) -> Void,
               onFinal: @escaping (String) -> Void) throws

    /// 停止听写并释放音频会话。停止后若仍有一段未达句末标点的尾句，
    /// 实现应再回调一次 onFinal（尾句）再结束（R-E2 尾句并入 / 单独成条）
    func stop()
}
```

### 2.2 Kotlin 接口（suspend + 回调，配合协程/主线程调度）

```kotlin
import kotlinx.coroutines.suspendCancellableCoroutine

enum class PermissionState {
    NOT_DETERMINED,   // 未请求
    GRANTED,          // 已授权
    DENIED,           // 用户拒绝
    RESTRICTED,       // 系统限制
    UNAVAILABLE       // 不支持 / 语言包缺失
}

interface ASRController {
    /** 当前是否可用（语言包/能力层判断） */
    val isAvailable: Boolean

    /** 请求授权，返回最终状态（首次弹系统授权） */
    suspend fun requestPermission(): PermissionState

    /**
     * 开始持续听写。
     * @param onPartial 流式中间结果（实时刷新输入框）
     * @param onFinal   确定句段边界产出的最终文本，调用方据此落库
     * @throws IllegalStateException 当音频引擎/识别器不可用
     */
    fun start(
        onPartial: (String) -> Unit,
        onFinal: (String) -> Unit
    )

    /** 停止听写并释放资源；停止前对尾句再回调一次 onFinal */
    fun stop()
}
```

### 2.3 协议语义约束（双端一致）

- `start` 调用前**必须**已 `requestPermission() == .granted`；否则实现应抛错 / 直接回调降级，不得静默无反应。
- `onPartial` 在 `start` 后高频触发，UI 仅用于**展示**，不可作为落库依据。
- `onFinal` 每次代表一个「可落库句段」边界：来源为「句末标点切分结果」或「长停顿边界」或「端侧识别结束」。领域层 `VoiceTaskSplitter` 在 `onFinal` 内做标点切分与落库（见 §5）。
- `stop()` 后实现必须保证：残留尾句以一次 `onFinal` 收尾（即使无句末标点，也单独成条；若空则不回调，R-X4），随后停止音频。
- 实现内部在 `onFinal`/`onError` 中处理「离线优先→联网回退→失败降级」链路（P0-1，见 §3/§4/§6）。

## 3. iOS 方案（SFSpeechRecognizer + AVAudioEngine）

### 3.1 接入与持续听

```swift
import Speech
import AVFoundation

final class NativeASRController: ASRController {

    private let audioEngine = AVAudioEngine()
    private var request: SFSpeechAudioBufferRecognitionRequest?
    private var task: SFSpeechRecognitionTask?
    private let speechRecognizer: SFSpeechRecognizer?
    private let splitConfig: ASRSplitConfig        // 来自 shared/asr_split_config.json（单例）
    private var onPartial: ((String) -> Void)?
    private var onFinal: ((String) -> Void)?
    private var silenceMonitor: SilentPauseMonitor? // 依据 splitPauseThresholdMs 检测长停顿

    init(config: ASRSplitConfig) {
        self.splitConfig = config
        self.speechRecognizer = SFSpeechRecognizer(locale: Locale(identifier: "zh-CN"))
    }

    var isAvailable: Bool {
        // 设备能力 + 中文语言可用性；不触发授权弹窗
        (speechRecognizer?.isAvailable ?? false)
    }

    func requestPermission() async -> PermissionState {
        // 1) 语音识别授权
        let speechAuth = await withCheckedContinuation { cont in
            SFSpeechRecognizer.requestAuthorization { status in cont.resume(returning: status) }
        }
        guard speechAuth == .authorized else {
            return mapSpeechAuth(speechAuth)   // denied / restricted / unavailable
        }
        // 2) 麦克风授权（AVAudioSession 录权限）
        let micAuth = await withCheckedContinuation { cont in
            AVAudioSession.sharedInstance().requestRecordPermission { granted in cont.resume(returning: granted) }
        }
        guard micAuth else { return .denied }
        return .granted
    }

    func start(onPartial: @escaping (String) -> Void,
               onFinal: @escaping (String) -> Void) throws {
        self.onPartial = onPartial
        self.onFinal = onFinal

        // 音频会话
        let session = AVAudioSession.sharedInstance()
        try session.setCategory(.record, mode: .measurement, options: .duckOthers)
        try session.setActive(true, options: .notifyOthersOnDeactivation)

        // 识别请求：持续听 + 流式 partial + 听写提示
        let req = SFSpeechAudioBufferRecognitionRequest()
        req.shouldReportPartialResults = true        // 流式中间结果
        req.taskHint = .dictation                      // 听写场景
        req.requiresOnDeviceRecognition = true        // 离线优先（iOS 13+，需设备已下载中文离线包）
        self.request = req

        let inputNode = audioEngine.inputNode
        let fmt = inputNode.outputFormat(forBus: 0)
        inputNode.installTap(onBus: 0, bufferSize: 1024, format: fmt) { [weak self] buffer, _ in
            self?.request?.append(buffer)
            self?.silenceMonitor?.feed(buffer)        // 驱动长停顿检测
        }
        audioEngine.prepare()
        try audioEngine.start()

        // 启动长停顿监控（splitPauseThresholdMs 来自配置，禁止硬编码）
        let monitor = SilentPauseMonitor(thresholdMs: splitConfig.splitPauseThresholdMs,
                                         onPauseExceeded: { [weak self] in
            // 长停顿 > 阈值：把当前已识别文本作为 final 边界吐出（由领域层再切分）
            self?.flushFinalBoundary()
        })
        self.silenceMonitor = monitor
        monitor.start()

        // 识别任务
        task = speechRecognizer?.recognitionTask(with: req) { [weak self] result, error in
            guard let self else { return }
            if let result, result.isFinal == false {
                let text = result.bestTranscription.formattedString
                self.onPartial?(text)                  // 实时显示
            }
            if let result, result.isFinal {
                // 端侧识别结束：本次 final 文本交给领域层落库
                let text = result.bestTranscription.formattedString
                self.onFinal?(text)
                self.silenceMonitor?.reset()
            }
            if let error {
                self.handleRecognitionError(error)      // 见 §6 降级链路
            }
        }
    }

    func stop() {
        audioEngine.stop()
        audioEngine.inputNode.removeTap(onBus: 0)
        request?.endAudio()
        task?.cancel()
        task = nil
        request = nil
        silenceMonitor?.stop()
        try? AVAudioSession.sharedInstance().setActive(false, options: .notifyOthersOnDeactivation)
    }

    // 长停顿边界：把「当前 latest partial」作为一次 final 吐出，并清空避免重复落库
    private func flushFinalBoundary() {
        // 注：iOS 不直接提供「最新 partial 文本」句柄，实现应缓存最近一次 onPartial 文本；
        // 此处以缓存文本触发 onFinal（领域层会做标点切分与去尾标点）
        guard let buffered = latestPartialText, !buffered.trimmingCharacters(in: .whitespaces).isEmpty else { return }
        onFinal?(buffered)
        latestPartialText = nil
    }
}
```

### 3.2 离线优先 → 联网回退（P0-1）

- `request.requiresOnDeviceRecognition = true` 为首选（iOS 13+）。若设备**未下载中文离线包**，SFSpeechRecognitionTask 会回调 `error.localizedDescription` 含 `on-device` 相关失败（如 `kAFAssistantErrorDomain` / `SFSpeechRecognitionTaskErrorDomain`）。
- 回退策略：首次 `requiresOnDeviceRecognition=true` 失败 → 重新建 `request`（`requiresOnDeviceRecognition = false`）再 `recognitionTask` 一次，进入**联网识别**。
- 联网识别仍需网络；若仍失败（无网）→ 进入 §6 降级（关语音按钮 + Toast）。
- 首次回退时应以埋点 `voice_error(reason: offline→online_fallback)` 记录（仅本地，不上传账号）。

### 3.3 权限与 `Info.plist`

- `Info.plist` 必须含：
  - `NSSpeechRecognitionUsageDescription`（语音识别用途说明，文案含「语音经系统 ASR 在设备端或联网转写，弱网/离线可能上传音频至 Apple，可在设置关闭语音输入」）
  - `NSMicrophoneUsageDescription`（麦克风用途说明）
- 运行时先 `requestPermission()`（见 §3.1），拒绝 → `.denied` → 触发 §6 降级。

### 3.4 自动拆分在 iOS 侧的分工

- **partial**：实时显示在输入框（UI 层），不落库。
- **final**：每次识别结束 / 长停顿边界吐出 → 调 `VoiceTaskSplitter.commitFinalSegment(text)`（§5）按标点切分并落库 → 继续听。
- **尾句**：`stop()` 前对未达句末标点的缓冲再调一次 `onFinal`（§5 会作为单独一条或并入最后一条，遵循 R-E2 尾句处理）。

## 4. Android 方案（SpeechRecognizer）

### 4.1 接入与持续听循环

```kotlin
import android.content.Intent
import android.os.Bundle
import android.speech.RecognitionListener
import android.speech.RecognizerIntent
import android.speech.SpeechRecognizer
import java.util.Locale

class NativeASRController(
    private val context: Context,
    private val splitConfig: ASRSplitConfig          // 来自 assets/shared/asr_split_config.json（单例）
) : ASRController {

    private var recognizer: SpeechRecognizer? = null
    private var onPartial: ((String) -> Unit)? = null
    private var onFinal: ((String) -> Unit)? = null
    private var listening = false
    private val latestPartial = StringBuilder()       // 缓存当前句段，用于长停顿/停止收尾

    override val isAvailable: Boolean
        get() = SpeechRecognizer.isRecognitionAvailable(context)

    override suspend fun requestPermission(): PermissionState {
        // 麦克风权限（RECORD_AUDIO）由 UI 层用 ActivityCompat.requestPermissions 申请；
        // 本方法仅校验当前是否已授权（Android 无独立「语音识别」授权，识别能力随 Google 服务）
        return if (ContextCompat.checkSelfPermission(context, Manifest.permission.RECORD_AUDIO)
            == PackageManager.PERMISSION_GRANTED) PermissionState.GRANTED
        else PermissionState.DENIED
    }

    override fun start(onPartial: (String) -> Unit, onFinal: (String) -> Unit) {
        this.onPartial = onPartial
        this.onFinal = onFinal
        recognizer = SpeechRecognizer.createSpeechRecognizer(context).apply {
            setRecognitionListener(buildListener())
        }
        listening = true
        beginListening()                               // 首次启动
    }

    // 单次识别意图（FREE_FORM + zh-CN + 流式 partial + 离线优先）
    private fun beginListening() {
        val intent = Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply {
            putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL,
                     RecognizerIntent.LANGUAGE_MODEL_FREE_FORM)
            putExtra(RecognizerIntent.EXTRA_LANGUAGE, "zh-CN")
            putExtra(RecognizerIntent.EXTRA_PARTIAL_RESULTS, true)   // 流式中间结果
            // 离线优先：优先使用设备已下载离线语言包；无离线包时系统自动回退联网识别
            putExtra("android.speech.extra.EXTRA_PREFER_OFFLINE", true)
        }
        recognizer?.startListening(intent)
    }

    private fun buildListener() = object : RecognitionListener {
        override fun onPartialResults(partialResults: Bundle?) {
            val matches = partialResults
                ?.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION) ?: return
            val text = matches.firstOrNull() ?: return
            latestPartial.clear().append(text)
            onPartial?.invoke(text)                    // 实时显示
        }

        override fun onResults(results: Bundle?) {
            val matches = results
                ?.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)
            val text = matches?.firstOrNull().orEmpty()
            if (text.isNotEmpty()) {
                latestPartial.clear()
                onFinal?.invoke(text)                  // 一个句段边界完成
            }
            // 持续听循环：结束即重启（onEndOfSpeech 视为一条完成，见 4.2）
            if (listening) beginListening()
        }

        override fun onEndOfSpeech() {
            // 端侧判定一条说完：当前缓冲作为 final 边界吐出（领域层再切分）
            val text = latestPartial.toString()
            if (text.isNotEmpty()) {
                onFinal?.invoke(text)
                latestPartial.clear()
            }
            // onEndOfSpeech 后系统会自动触发 onResults，再由 onResults 内重启循环
        }

        override fun onError(error: Int) {
            handleError(error)                         // 见 §6 降级链路
        }

        override fun onReadyForSpeech(params: Bundle?) {}
        override fun onBeginningOfSpeech() {}
        override fun onRmsChanged(rmsdB: Float) {
            // 可驱动长停顿检测：rms 低于静音阈值累计 > splitPauseThresholdMs → 触发 final 边界
        }
        override fun onBufferReceived(buffer: ByteArray?) {}
        override fun onEvent(eventType: Int, params: Bundle?) {}
    }

    override fun stop() {
        listening = false
        // 停止前：把尾句（未达句末标点的缓冲）作为一次 final 收尾
        val tail = latestPartial.toString()
        if (tail.isNotBlank()) onFinal?.invoke(tail)
        recognizer?.stopListening()
        recognizer?.cancel()
        recognizer?.destroy()
        recognizer = null
    }
}
```

### 4.2 自动拆分在 Android 侧的分工

- **`EXTRA_PARTIAL_RESULTS=true`**：`onPartialResults` 实时显示（不落库）。
- **`onResults` / `onEndOfSpeech`**：视为一个句段边界 → `onFinal` 交给领域层切分落库 → 立即 `beginListening()` 形成持续听循环。
- **长停顿**：由 `onRmsChanged` 监测静音时长，累计 > `splitConfig.splitPauseThresholdMs`（**禁止硬编码 1200**）时，主动把当前 `latestPartial` 作为 `onFinal` 吐出（对应 P0-4 长停顿 >1.2s），随后由 `onResults` 重启循环。
- 句末标点切分由领域层 `VoiceTaskSplitter` 在 `onFinal` 内完成（见 §5），平台层不切分。

### 4.3 离线优先 → 联网回退（P0-1）

- 优先 `EXTRA_PREFER_OFFLINE=true`（设备已下载中文离线包时走设备端）。
- 离线包缺失/失败 → 系统自动回退**联网识别**（Google 语音服务）。
- 联网仍失败（`ERROR_NETWORK`）→ 进入 §6 降级。

### 4.4 权限、`AudioFocus` 与降级触发

- 权限：`RECORD_AUDIO`，由 UI 层 `ActivityCompat.requestPermissions` 在进语音入口前申请（R-E9 / AC-21）；拒绝 → `PermissionState.DENIED` → §6 降级。
- `AudioFocus` 抢占（来电/其他 App 占用麦克风）：监听 `AudioManager.AUDIOFOCUS_LOSS` → `stop()` 暂停；恢复 `AUDIOFOCUS_GAIN` → 重新 `start()`（持续听不中断记录流）。
- `onError` 映射（§6）：`ERROR_NO_MATCH` / `ERROR_NETWORK` / `ERROR_INSUFFICIENT_PERMISSIONS` → 降级。

```
FUNCTION splitIntoSegments(text, config) -> List<String>:
    segments = []
    buffer = ""
    FOR char IN text:
        // 1) 仅当 char 属于 config.splitPunctuation 时切分（不含「、」/换行，由配置决定）
        IF char IN config.splitPunctuation:
            flush(buffer)                    // 句末标点前的内容作为一个段
            buffer = ""                      // 标点本身丢弃（不进 title）
        ELSE IF (char == '、' AND NOT config.includeEnumerationComma):
            buffer += char                   // 顿号保留，并入当前条，不切
        ELSE IF (char == '\n' AND NOT config.includeNewline):
            buffer += char                   // 换行保留，并入当前条，不切
        ELSE:
            buffer += char
    IF buffer.trim().isNotEmpty():
        segments.append(buffer.trim())       // 尾段（无句末标点）也成条
    RETURN segments

FUNCTION flush(buffer):
    IF buffer.trim().isNotEmpty():
        segments.append(buffer.trim())

// —— 长停顿边界：平台层在静音 > config.splitPauseThresholdMs 时调用一次 commitFinalSegment(currentBufferedText)
// —— 句末标点边界：平台层在 onFinal 回调时调用一次 commitFinalSegment(text)

FUNCTION commitFinalSegment(text, config, repository):

        IF seg.isEmpty(): CONTINUE          // R-X4：不生成空待办

                    syncState = .local)
        repository.add(task)                 // M1 接口；落库即触发 UI 刷新（@FetchRequest/Flow）
```

```swift
// Swift
final class VoiceTaskSplitter {
    private let config: ASRSplitConfig
    private let repository: TaskRepository
    private let punctuationSet: Set<String>

    init(config: ASRSplitConfig, repository: TaskRepository) {
        self.config = config
        self.repository = repository
        self.punctuationSet = Set(config.splitPunctuation)
    }

    /// 平台层在「句末标点 / 长停顿边界 / onFinal」时调用
    func commitFinalSegment(_ text: String) {
        for seg in splitIntoSegments(text) where !seg.isEmpty {
            let task = TaskDTO(title: seg,
                              date: Self.todayString(),
                              source: .voice)
            try? repository.add(task)         // M1 协议
        }
    }

    private func splitIntoSegments(_ text: String) -> [String] {
        var segs: [String] = []
        var buf = ""
        for ch in text {
            let s = String(ch)
            if punctuationSet.contains(s) {
                let t = buf.trimmingCharacters(in: .whitespacesAndNewlines)
                if !t.isEmpty { segs.append(t) }
                buf = ""
            } else if s == "、" && !config.includeEnumerationComma {
                buf.append(s)                 // 顿号并入，不切
            } else if (s == "\n" || s == "\r") && !config.includeNewline {
                buf.append(s)                 // 换行并入，不切
            } else {
                buf.append(ch)
            }
        }
        let tail = buf.trimmingCharacters(in: .whitespacesAndNewlines)
        if !tail.isEmpty { segs.append(tail) }
        return segs
    }

    static func todayString() -> String {
        let f = DateFormatter(); f.dateFormat = "yyyy-MM-dd"
        f.timeZone = .current; return f.string(from: Date())
    }
}
```

```kotlin
class VoiceTaskSplitter(
    private val config: ASRSplitConfig,
    private val repository: TaskRepository
) {
    private val punctuationSet: Set<String> = config.splitPunctuation.toSet()

    /** 平台层在「句末标点 / 长停顿边界 / onFinal」时调用 */
    fun commitFinalSegment(text: String) {
        splitIntoSegments(text).filter { it.isNotBlank() }.forEach { seg ->
            val task = Task(
                id = UUID.randomUUID().toString(),
                title = seg,
                date = todayString(),
                source = TaskSource.VOICE,                 // raw "voice"
                categoryId = OTHER_CATEGORY_ID,            // 其他（M1 §3.2）
                priority = Priority.MEDIUM,
                updatedAt = Date(),
                syncState = SyncState.LOCAL
            )
            runBlocking { repository.add(task) }           // M1 接口
        }
    }

    private fun splitIntoSegments(text: String): List<String> {
        val segs = mutableListOf<String>()
        val buf = StringBuilder()
        for (ch in text) {
            val s = ch.toString()
            when {
                punctuationSet.contains(s) -> {
                    val t = buf.toString().trim()
                    if (t.isNotEmpty()) segs.add(t)
                    buf.clear()
                }
                s == "、" && !config.includeEnumerationComma -> buf.append(s)
                (s == "\n" || s == "\r") && !config.includeNewline -> buf.append(s)
                else -> buf.append(ch)
            }
        }
        val tail = buf.toString().trim()
        if (tail.isNotEmpty()) segs.add(tail)
        return segs
    }

    private fun todayString(): String {
        val f = SimpleDateFormat("yyyy-MM-dd", Locale.getDefault()); return f.format(Date())
    }

    companion object {
        const val OTHER_CATEGORY_ID = "00000000-0000-0000-0000-000000000004"
    }
}
```

### 5.4 关键规则（双端一致，对应 P0-4 / R-E2 / AC-3）

1. **标点集切分**：仅 `config.splitPunctuation`（当前 = `{ 。！？； }`）触发切分；段尾标点**丢弃**，不进入 `title`。
2. **不含「、」**：`includeEnumerationComma=false` → 顿号保留在 `title` 内，不切（避免一条清单被误拆）。
3. **不含换行**：`includeNewline=false` → 换行保留在 `title` 内，不切（同一条内的换行李内容）。
4. **长停顿**：由平台层用 `config.splitPauseThresholdMs`（当前 1200）监测并触发一次 `commitFinalSegment`（边界），领域层不直接计时不硬编码。
5. **用户手动「落一条」始终优先**：UI 侧「落一条」按钮 → 直接把当前输入框/最新 partial 文本调 `commitFinalSegment`（即便未达标点/停顿），覆盖自动信号（R-E2 用户手动优先）。
6. **空/静音不落库**：段为空 → 跳过（R-X4 / AC-4）。
7. **与 M1 接口对齐**：仅 `repository.add(_:)` 落库，`source = .voice`，无新增字段。

> **P0-4 防漂移校验点**：`splitPunctuation`、`splitPauseThresholdMs`、`includeEnumerationComma`、`includeNewline` 四者在 Swift/Kotlin **任何位置均不得出现字面量常量**；CI/Code Review 应检查无硬编码 `"。！？；"`、`1200` 等。唯一来源是 `shared/asr_split_config.json`。

## 6. 失败降级（Unwanted，R-X1 / AC-6）

> 链路目标：授权拒 / 无网且无离线包 / 识别失败 → 关闭语音按钮 + Toast 引导「改用文字输入」，记录流不中断；提供「停止并保存当前已识别文本」作为文字条目。

### 6.1 降级触发条件（双端统一）

| 触发 | iOS | Android |
|------|-----|---------|
| 识别授权被拒 | `SFSpeechRecognizer.requestAuthorization` ≠ authorized | （无独立识别授权，等同麦克风） |
| 麦克风权限拒 | `AVAudioSession.requestRecordPermission` = false | `RECORD_AUDIO` 未授予（`.DENIED`） |
| 无网且无离线包 | `requiresOnDeviceRecognition=true` 失败且联网也失败 | `EXTRA_PREFER_OFFLINE` 失败且 `ERROR_NETWORK` |
| 识别失败 | recognitionTask error（`on-device` 不可恢复 / 未知错误） | `ERROR_NO_MATCH` / `ERROR_NETWORK` / `ERROR_INSUFFICIENT_PERMISSIONS` / `ERROR_CLIENT` |
| AudioFocus 永久丢失 | 不可恢复抢占 | `AUDIOFOCUS_LOSS` 且无法恢复 |

### 6.2 降级处理伪代码（双端同语义）

```kotlin
// Android
private fun handleError(error: Int) {
    when (error) {
        SpeechRecognizer.ERROR_INSUFFICIENT_PERMISSIONS -> degrade(PermissionState.DENIED)
        SpeechRecognizer.ERROR_NETWORK -> {
            if (!didFallbackToOnline) { didFallbackToOnline = true; beginListening() } // 重试联网

        }

    }
}
```

### 7.2 行为约束（双端一致，对应 AC-5 / R-E8）

- `merge`：保留参与合并各条的**最早 `date`、最前 `sortOrder`**；合并后 `title` 用「、`」连接（与 P0-4「、」不切分语义一致）；`remindAt` 取合并中首个有提醒者；合并后调用 `repository.delete` 移除被并条目 + `repository.add/update` 新条；`updatedAt` 刷新。

- **埋点调用点**：`todo_merge` / `todo_split`（PRD §11），仅标注不写上报。

## 8. P0-1 隐私说明

1. **联网识别性质**：语音 ASR **优先设备端**（iOS `requiresOnDeviceRecognition=true`、Android `EXTRA_PREFER_OFFLINE=true`）；设备端不可用（未装离线包/授权失败/识别失败）时**联网回退**（P0-1 方案 C）。

3. **无云端写路径**：v1 仍**无云端持久化 / 上传待办的写路径**（不新增任何上传逻辑），符合「纯本地零登录」定位；语音联网仅限识别链路，不触达数据存储（架构 §1.2 原则 #4）。
4. **用户控制**：设置页提供「语音输入开关」可关闭；关闭后仅文字录入。权限状态可见并可跳系统设置重授权（AC-22）。
5. **文案（进设置页 / 首次语音引导，对应 PRD §9）**：
   - 麦克风授权描述（iOS `NSMicrophoneUsageDescription` / Android 运行时说明）：「用于语音记录待办；语音经系统 ASR 在设备端或联网转写，弱网/离线可能上传音频至系统厂商（Apple/Google），可在设置关闭语音输入。」
   - 隐私总说明：「本 App 纯本地存储、零登录；语音经系统 ASR 在设备端或联网转写，弱网/离线场景可能将音频上传至系统厂商完成识别，非上传至本 App 账号/服务端；无个人数据随账号出端。」
